# Fotografías reales de Madeartex Diseño

Guarda aquí las fotos propias (jpg, png, webp o avif) usando el mismo nombre de archivo que la imagen de
referencia que reemplazan (ver `src/data/reference-images.json`), por ejemplo `closet-vidrio.jpg`.

Tienen prioridad automática sobre las imágenes de referencia y el aviso de "imagen de referencia" desaparece.
